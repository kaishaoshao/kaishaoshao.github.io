# 4.3 用入口地址和退出码排查故障

从装载、启动、函数调用和结果检查四处定位第一次失败。

- **操作** 对第 4.2 节的 ELF 运行 `llvm-readelf -h -l -s` 和 `llvm-objdump -d`。在输出中找到 `_start`、其调用的设备函数、输出缓冲地址和设备退出路径。再对照 L03.0 的两次退出码。
- **测试与通过标准** 用同一个设备对象重新链接两份镜像，分别将第 4.2 节的 `EXPECTED_STORE` 设为 42 和 43。保存各自的 ELF 路径和退出码，预期为 0 和 1。对照反汇编确认修改落在检查入口，设备函数仍写入 42。
- **实现注意** 若失败发生在装载前，先看 `ET_EXEC`、`PT_LOAD`、`e_entry` 和实际加载路径。若在设备执行时失败，从入口顺序核对栈、指针、可用指令和退出路径。保留 SimX 的诊断及对应的镜像版本。

这节练习的结果由设备侧检查后返回进程状态。下一章会让 host 通过 SDK 读回设备输出。
