# 11.2 从 BAR 指令接到块内屏障

把 `__syncthreads()` 接到 Vortex 屏障，再通过读写观察核对可见性和编译器重排。

> 本节为进阶实验提纲。

- **操作** 对照参考 SDK barrier 包装、LLVM 的 intrinsic 属性和执行端等待机制。定义哪些线程参与、哪些写入需要对本 block 可见。
- **测试与通过标准** 用合法的多 warp block 写共享数据、同步再互读，对 block 内 global 数据重复同一测试。在 `-O0/-O2` 和多轮循环中执行，对照正确值并检查屏障前后的指令顺序。
- **实现注意** 分别验证执行汇合、内存可见性与编译器重排。测试保证各参与线程按契约到达屏障，避免用分歧屏障当成正常输入。
