# 12.2 接通 stream 和队列内顺序

把一组有依赖的拷贝与 kernel 放进同一条流，查清执行顺序与销毁时机。

> 本节为进阶实验提纲。

- **操作** 以 SDK 队列表示初版 stream，接通创建、提交、同步和销毁，记录支持的 flag 与默认流交互规则。
- **测试与通过标准** 在同一 stream 排队执行写入、kernel、读回。最后同步时应读到新结果。向两个 stream 分别提交独立工作，核对资源隔离与销毁行为。
- **实现注意** 明确 FIFO 的保证范围和同步返回时已完成的工作。默认流的规则以项目选定的 HIP 子集为准。
