# 12.3 用事件连接两个 stream

让一条流依赖另一条流的输出，确认数据就绪和资源保活使用同一次事件记录。

> 本节为进阶实验提纲。

- **操作** 在生产者流记录 event，在消费者流等待它，随后发起 kernel 或读回。画出 event 记录、任务完成和 buffer/module/host staging 释放之间的关系。
- **测试与通过标准** 两条流构成依赖后，读回与 CPU 参考一致。覆盖重记 event、未完成查询和在途 buffer 销毁。注明哪些异步拷贝模式可以安全完成。
- **实现注意** 缓冲区和参数快照必须有效到任务完成，记录 host 内存要求与允许的阻塞回退。仿真这里验收的是依赖和结果。
