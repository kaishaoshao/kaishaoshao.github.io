# 12.4 发布可复现的原型

让另一份全新构建能复现已支持的编译和执行路径。

> 本节为进阶实验提纲。

- **操作** 固定 LLVM、SDK、runtime、头文件、构建参数和仿真配置。把课程的代表输入与已验证的特性写成支持矩阵，整理构建与重跑步骤。
- **测试与通过标准** 从新目录重建并重跑准备交付的用例。分别追到 host 嵌入的镜像、实际 runtime 和设备配置，将每项结果与日志、CPU 参考及镜像指纹关联。
- **实现注意** 将默认配置、A-enabled 配置和仍复用的参考库逐项记录。标明当前完成的范围，待实现的能力留在各自的任务卡。
