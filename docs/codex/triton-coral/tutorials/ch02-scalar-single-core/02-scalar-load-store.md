# 2.2 节：标量访存：无掩码 i32 load/store 转换

## 1. 这节课做什么
- **功能目标**：将无掩码 I32 的拷贝降为 LLVM 访存。
- **支持语法**：`tl.load(X), tl.store(Y, val) 标量单元素无 mask 访存`
- **涉及方言**：tt.load / tt.store -> llvm.load / llvm.store
- **阶段标记**：`S1-01b`（所属章节：第 2 章：标量语法降级与单核 AOT 执行闭环）
- **实现注意**：仅在 ABI 保证对齐时标注对齐。用非法张量或 mask 负例检查未支持的转换。
