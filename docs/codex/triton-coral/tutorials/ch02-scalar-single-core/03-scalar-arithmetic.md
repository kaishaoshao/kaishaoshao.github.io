## 1. 这节课做什么
- **功能目标**：接入 constexpr 常量和 I32 加法，沿用第一批的 LLVM IR 导出。
- **支持语法**：`x + 1, tl.constexpr 常量运算与 INT32 回绕`

- **阶段标记**：`S1-01c`（所属章节：第 2 章：标量语法降级与单核 AOT 执行闭环）
- **实现注意**：保留 I32 回绕。对照拷贝和加法的 LLVM IR，确认计算来自源码，避免擅加 nsw 或 nuw。
